# BinBuddy

### 🗑️ 스마트한 분리배출을 위한 AI 기반 도우미

BinBuddy는 이미지 분석 및 분류 기능을 통해 사용자가 재활용품 및 일반 쓰레기를 효율적으로 분리배출할 수 있도록 돕는 AI 기반 웹 애플리케이션입니다.

---

## 📋 프로젝트 개요

- **주요 기능**:
  1. 업로드된 이미지 분석
  2. 쓰레기 분류 및 카테고리화
  3. 분석된 결과를 시각화된 박스로 표시
  4. 특정 영역별 캡처 이미지 제공
  5. Gemini 모드에서 추가 가이드라인 제공

- **주요 기술 스택**:
  - Frontend: Vue.js, JavaScript, CSS
  - Backend: Flask 기반 API (외부 제공)
  - 상태 관리: Pinia
  - 디자인 및 스타일링: SCSS, Responsive Design

---

## 📦 주요 기능 설명

### 1. 이미지 업로드 및 분석
- 파일 업로드 또는 카메라 촬영을 통해 이미지를 입력.
- 업로드된 이미지를 AI가 분석하여 분류 및 가이드라인 제공.

### 2. 분석 결과 표시
- 각 쓰레기 객체를 탐지하여 화면에 박스로 표시.
- 탐지된 쓰레기 카테고리를 색상별로 구분.

### 3. 영역 캡처 및 세부 정보
- 분석된 각 객체의 이미지를 캡처하여 하단에 표시.
- 카테고리 버튼 클릭 시 해당 객체만 필터링 가능.

### 4. Gemini 모드
- 재활용 관련 추가 가이드라인 제공.
- Gemini 버튼 클릭 시 가이드라인 섹션으로 전환.
